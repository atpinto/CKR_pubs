About this collection & keeping it up to date

Data file. The collection contains 0 records loaded from publications.csv. Keep that file beside this HTML page. GitHub Pages loads it automatically; when opening the HTML directly from a computer, use Open CSV file.

Automatic updates. The included GitHub Actions workflow runs every Monday at 7:00 am in the Australia/Sydney timezone. It queries PubMed, refreshes the CSV, preserves manually curated project/programme assignments and commits the result. Use Reload latest CSV after an automated run, or reopen the page.

Manual records and associations. Use Add publication and enter a PMID to populate its citation from PubMed, or fill the fields yourself. Every record has an Edit record & associations button. Enter one project or programme per line. Browser edits are not sent to GitHub automatically; download the current CSV and commit it after manual changes.

CSV format. The associations are ordinary text in the projects and programmes columns, separated by | . Multi-value citation fields use JSON arrays so commas and semicolons round-trip safely. Spreadsheet applications can open and save the file as UTF-8 CSV.

Coverage. The weekly updater uses the Centre/Center for Kidney Research affiliation query and retains only matching Sydney, Westmead, New South Wales or NSW affiliations. Existing records that can no longer be verified are retained with a review label. Manually added non-PubMed records are never removed.

EndNote. “Export to EndNote” downloads the currently filtered records as a RIS file. In EndNote Online, import it using RefMan RIS. Project and programme assignments are included as searchable keywords.

Each PubMed record links to its source. A PubMed search alert is also available.
