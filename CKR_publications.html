About this collection & keeping it up to date

Live data. The collection contains 0 records loaded from a Supabase PostgreSQL database. The committed publications.csv remains a portable backup.

Automatic updates. The GitHub Actions workflow runs every Monday at 7:00 am in the Australia/Sydney timezone. It queries PubMed, refreshes the database and CSV backup, and preserves manually curated project/programme assignments.

Manual records and associations. Approved editors sign in with email and password. Use Add publication and enter a PMID to populate its citation from PubMed, or fill the fields yourself. Every record then has an Edit record & associations button. Enter one project or programme per line. Clicking Save record writes the change directly to the database and records it in the audit history.

CSV backup. The associations are text in the projects and programmes columns, separated by | . Multi-value citation fields use JSON arrays so commas and semicolons round-trip safely.

Coverage. The weekly updater uses the Centre/Center for Kidney Research affiliation query and retains only matching Sydney, Westmead, New South Wales or NSW affiliations. Existing records that can no longer be verified are retained with a review label. Manually added non-PubMed records are never removed.

EndNote. “Export to EndNote” downloads the currently filtered records as a RIS file. In EndNote Online, import it using RefMan RIS. Project and programme assignments are included as searchable keywords.

Each PubMed record links to its source. A PubMed search alert is also available.
